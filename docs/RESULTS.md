## How to regenerate

```bash
python scripts/reproduce_paper.py --config configs/paper.yaml \
    --export-final-results
```

This regenerates all result files from the raw dataset.

## Reference vs reproduced values

- **Reference values** are transcribed directly from the published paper and
  serve as the target the reconstruction aims to approximate.
- **Reproduced values** are generated by running this implementation on the
  Kaggle dataset. Differences arise from dataset version, library versions,
  random seeds, and reconstruction assumptions documented in
  `docs/IMPLEMENTATION_ASSUMPTIONS.md`.
- Neither set of values constitutes investment advice.
